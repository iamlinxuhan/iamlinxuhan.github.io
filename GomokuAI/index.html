GomokuAI v4.3.1

一个不断打磨的五子棋 AI。位棋盘、全增量评估、Negamax/PVS、置换表、静止搜索与 VCF 连续冲四， 一层层把搜索压进时间里；C++17 搜索核心纯 CPU 运行，支持挑战 AI、本地对战与局域网联机。 现已以 AlphaGomoku 之名上架 Microsoft Store。

  • Python
  • PyQt5
  • C++17
  • CPU only

deb 安装后从菜单启动；裸文件需要先 chmod +x。普通使用选 play，排查问题选 debug。

macOS 暂未提供

本仓库的 C++ 搜索核心只在 Windows / Linux 上构建，从未在 macOS 上开发或验证。 macOS 用户请前往 GomokuAI-Py， 那里提供 Apple Silicon 与 Intel 的 .dmg / .pkg。

其他架构 aarch64 · armv7 · amd_x32 用 uname -m 对照：aarch64 → ARM64，armv7l → armv7，i686 → amd_x32；tar.gz 解包后运行 sudo ./install.sh。

下载由 Cloudflare 缓存加速。若暂时无法下载，可前往 GitHub Releases。
